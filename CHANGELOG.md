# Changelog

## 0.3.0 — 2026-11-15

- Integrate reference reconstruction, novel-to-episodic-drama and original/reference-derived stories in one self-contained `video-creation` entry.
- Share briefs, source coverage, character knowledge, setup/payoff memory and production handoffs across routes.
- Add standard-library source registration, UTF-8 chunk reading, hash invalidation, continuation and versioned artifact records.
- Add a fictional prose source and three-route walkthroughs; distinguish creative guidance, executable tools and actual media evidence.

Video generation, recurring dialogue voices, platform posting and a full novel-to-series production run remain backend-specific work, not bundled automation.

## 0.2.0 — 2026-11-15

- Add CPU local-video observation: metadata, per-shot coverage, timestamped windows, context-linked crops and an observer-attested journal.
- Add the self-contained `video-observation` skill for broad attention, body language and interaction; image export never marks content approved.
- Preserve real source timestamps and frame identity, including variable frame rates; use temporary synthetic media for integration tests.
- Connect observation findings to performance direction while keeping interpretation and unobserved rhythm/audio separate.

No cloud service, local video model, automatic downloader or MCP server is required.

## 0.1.0 — 2026-11-15

- First public skill for reference performance essence and original visual highlights.
- Six-part event card, attention handoff and evidence-aware production review.
- Fictional reference and human-character examples; ten-case text evaluation set.
- English and Chinese onboarding, source attribution and a thin Claude Code plugin wrapper.
- Package portability checks and negative fixtures.

This release is an instruction package. It includes no video model, media server, automatic publishing service or measured video-quality benchmark.
