# Changelog

## 0.2.0 — 2026-11-15

- Add CPU local-video observation: metadata, per-shot coverage, timestamped windows, context-linked crops and an observer-attested journal.
- Add the self-contained `video-observation` skill for broad attention, body language and interaction; image export never marks content approved.
- Preserve real source timestamps and frame identity, including variable frame rates; use temporary synthetic media for integration tests.
- Connect observation findings to performance direction while keeping interpretation and unobserved rhythm/audio separate.

No cloud service, local video model, automatic downloader or MCP server is required.
