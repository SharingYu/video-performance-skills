# Five-minute text walkthrough

These are **fictional illustrative texts, not media tests**. No video was rendered, no model comparison was run, and no audience response was measured. Miso, Nori, Alex, and Robin are invented characters.

Choose one route:

| Route | Give your agent | Ask it to produce |
| --- | --- | --- |
| Preserve a reference performance | [Reference input](reference/input.md) | One six-group event card, with observations separated from interpretation |
| Invent a visual highlight | [Original input](original/input.md) | Three different mechanisms, an editorial choice, and one six-group event card |

1. Open the repository's `performance-direction` skill, linked from the root README, in a compatible agent host. Make the agent read the skill and the chosen input. Merely opening this folder does not load the skill.
2. Use one of the requests below. Neither exercise needs a GPU, video model, or media service; it does require an agent host with a language model.
3. Read the agent's result before opening the corresponding example output. Check whether it preserves the causal middle, the partner's reaction, and who gets the viewer's attention.
4. Compare with [reference output](reference/output.md) or [original output](original/output.md). These are worked examples, **not evaluation answer keys**. Other choices can work if they preserve the stated relationships and label uncertainty.

Reference request:

> Read the performance-direction skill and reference/input.md. Work in reference mode. Use only the seven supplied records as observation evidence; do not invent unseen media. Produce one six-group event card. Distinguish head direction, visible gaze, and manipulation target. Identify which middle actions would be lost even if the start and end matched.

Original request:

> Read the performance-direction skill and original/input.md. Work in original mode. Propose three mechanisms that differ in how the visual comedy works. Select one with an explicit editorial rationale, then make its six-group event card. Keep reactions playable and explain what remains untested.

An event phase is not automatically a shot. Do not assign fixed durations or add facial motion to every beat. These exercises stop at design: actual footage would still need separate checks for action, continuity, highlight visibility, and rhythm.
