# Fictional Dialogue and Reaction Example

This is original teaching text, with proposed timing and acting. No source film, audio, ASR run, speaker-identification result or media-quality pass is represented here. The examples work with human, stylized or other suitable performers; they are not fixed cat-series requirements.

## Scene: the reversible shop sign

Two shopkeepers are straightening a hanging sign. One side says “Open”; the other says “On a break.” Lin carefully judges the angle; Yue is eager to help.

| Proposed order | Proposed words | Proposed visible action / response | Why keep it |
|---|---|---|---|
| 1 | Lin: “先别动，我来。” (“Don't move it yet. I'll do it.”) | Yue's helping hand stops and withdraws; attention goes to Lin. | “别” explains the withdrawal. Dropping it changes the cue. |
| 2 | No new line | Lin nudges the lower edge. The sign flips to “On a break.” Yue reads it, looks at Lin, then sits on a stool. | The unintended instruction becomes readable before Yue acts on it. |
| 3 | Lin: “不是让你休息。” (“I didn't mean you should take a break.”) | Lin looks from Yue back to the sign, still holding the level. Yue turns one palm toward the “On a break” message. | The reply reveals Lin's realization; Yue's answer remains visible without another spoken explanation. |

## Event PE-D01

- **Expectation/payoff:** precision should fix the shop sign; the correction instead supplies an instruction that Yue takes literally.
- **Chain:** warning → helping hand withdraws → sign flips → Yue reads and sits → Lin realizes the new meaning.
- **Protected details:** D01-A retains the warning's negation; D01-B reveals the reversed sign before the sit; D01-C keeps Lin's delayed recognition and Yue's unhurried response visible. No fixed pause duration is prescribed.
- **Attention:** Lin's line transfers focus to the hand and sign; Yue's glance then transfers it to the stool; Lin's reply returns it to the sign.
- **May change:** shop, sign material, cast and style. **Must work:** legible reversible message, reachable sign, visible stool and a view that lets the audience read the change before the response.
- **Evidence boundary:** all words, order and performance above are a proposal. Visual geometry, typography, actual delivery, timing and generated-media continuity require production testing.

## Applying this to a real reference

Keep the real source version and use actual manifest line IDs rather than these design labels. If ASR returns “先动，我来” while the caption says “先别动，我来,” retain both and revisit the matching audio; the expected action is not proof of the missing word. If the host can only read ASR and inspect images, it may describe an ASR-derived warning and visible withdrawal, but cannot say the exact line or its intonation was heard.

If an imported diarization result labels both voices `SPEAKER_00`, keep that machine label. The distinction between Lin and Yue still needs scene evidence; one voice actor could perform both. An unseen speaker remains unknown. The sign's message is visible text, separate from spoken dialogue and from a subtitle track.
